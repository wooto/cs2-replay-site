Information accessed and collected

CS2 Replay Local Admin uses YouTube API Services. With your authorization it checks your YouTube channel identifier and reads the channel, visibility and processing status of uploaded videos, including private tests. You supply registered channel settings, local video paths, video files, titles, descriptions and review evidence. Recommendation collection reads FACEIT match data. When explicitly enabled, public YouTube discovery reads search results and video metadata without view statistics. Local job records include video identifiers, file hashes, upload progress and publication history.

The application requests youtube.readonly for channel and video checks and youtube.upload to send selected videos. It does not collect your Google password, request YouTube Analytics access or read watch history.

Use and sharing

Google user data is used to connect the channel you authorize, send selected videos and metadata to YouTube, and confirm upload results. Public discovery data is also used by the recommendation feature in the current development build. YouTube statistics are not used to compute recommendation scores.

Authorization requests, channel/video checks, and selected video files and metadata are sent to Google/YouTube. Recommendation requests may be sent to YouTube and FACEIT; optional Leetify discovery may be used when configured. There is no application-operated cloud database, advertising integration or analytics tracker. Google user data is not sold or used for advertising or to train AI models. Google API data use must comply with the Google API Services User Data Policy, including applicable Limited Use requirements.

Storage and security

Records are stored locally in SQLite on your Windows computer. OAuth credentials, tokens, API keys and resumable session URLs are encrypted for the current Windows user using DPAPI and are not returned to the browser. Other local records, including channel/job metadata and paths, are not encrypted by this application. Windows account and disk protections remain relevant. Requests to Google use HTTPS; the administration interface uses local loopback HTTP.

The local browser session uses an HttpOnly, SameSite cookie and expires after 12 hours. A one-use launch code establishes the session. No third-party cookies, advertising or remote tracking scripts are used by the admin. Google pages and YouTube separately apply their own policies. See the Google Privacy Policy.

Retention, disconnect and deletion

API response copies and upload jobs expire within 30 days while the server runs; expiry accumulated while stopped is applied on the next start. Recommendation reports and application-owned checkpoints also expire after 30 days. Channels not verified within 30 days lose their stored token and associated API job copies and require reconnection. Minimal owner-entered match reservations used for duplicate prevention, settings and policy acceptance remain until deletion.

Disconnect requests Google token revocation and immediately removes that channel's local token, upload sessions and jobs. Detected invalid_grant also clears affected channel data. Project-level revocation can affect other channel connections. You may revoke access independently in Google Account permissions.

The local data deletion control removes application settings, encrypted credentials and keys, channel/job/reservation records and the application's recommendation checkpoint. Stop active work before deletion. It does not revoke remote Google grants, delete YouTube videos, remove original MP4/report files or erase user-created exports and backups. Manage remote videos in YouTube Studio. Local deletion is logical deletion and does not guarantee forensic erasure from storage media.

수집·사용·공유

앱 운영자의 클라우드 DB, 광고·원격 추적 기능은 없습니다. Google 사용자 데이터를 판매하거나 광고 또는 AI 학습에 사용하지 않습니다. Google API 데이터는 해당 정책과 적용되는 Limited Use 요건에 따라 사용합니다. Google API Services User Data Policy.

저장·보호·보존

SQLite는 PC에 있습니다. OAuth JSON·토큰·API 키·업로드 세션은 Windows 사용자 범위 DPAPI로 암호화하며 브라우저에 다시 반환하지 않습니다. 기타 채널·작업 메타데이터는 앱에서 암호화하지 않습니다. Google 통신은 HTTPS이며 로컬 관리 화면은 loopback HTTP입니다. 관리 세션은 HttpOnly/SameSite cookie를 사용하며 12시간 동안 유지됩니다.

업로드 작업 및 API 응답 사본은 등록 후 최대 30일 이내에 앱이 실행 중일 때 정리합니다. 앱 종료 중 지난 기한은 다음 시작에서 적용합니다. 채널은 30일 이내 검증이 없으면 저장 토큰과 해당 API 작업을 삭제하고 재연결을 요구합니다. 공개 영상 발견 자료와 수집 체크포인트는 30일 만료 또는 새 수집으로 교체합니다. 중복 방지용 최소 경기 예약과 사용자가 입력한 설정은 사용자가 삭제할 때까지 남습니다. 정책 동의 버전·시각도 로컬에 저장합니다.
