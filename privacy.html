개인정보 처리방침

이 앱은 YouTube API Services를 사용해 소유자가 연결한 채널 ID와 업로드한 영상의 공개·처리 상태를 확인하고, 선택한 MP4와 제목·설명을 YouTube로 전송합니다. Google 비밀번호를 수집하지 않습니다. 요청 권한은 youtube.readonly와 youtube.upload입니다.

수집·사용·공유

채널 설정, OAuth 인증 정보, 업로드 작업·영상 ID·파일 경로·해시·검토 증거와 경기 선정 자료를 PC에 저장합니다. Google에는 인증·채널·영상 조회와 선택 영상·메타데이터 전송이 이루어집니다. 경기 추천은 FACEIT 성적과 최신성만 사용합니다. 선택적 YouTube 발견은 공개 영상 메타데이터를 사용하며 조회수 점수를 계산하지 않습니다. FACEIT와 선택적 Leetify에는 해당 자료 조회 요청을 보냅니다.

앱 운영자의 클라우드 DB, 광고·원격 추적 기능은 없습니다. Google 사용자 데이터를 판매하거나 광고 또는 AI 학습에 사용하지 않습니다. Google API 데이터는 해당 정책과 적용되는 Limited Use 요건에 따라 사용합니다. Google API Services User Data Policy.

저장·보호·보존

SQLite는 PC에 있습니다. OAuth JSON·토큰·API 키·업로드 세션은 Windows 사용자 범위 DPAPI로 암호화하며 브라우저에 다시 반환하지 않습니다. 기타 채널·작업 메타데이터는 앱에서 암호화하지 않습니다. Google 통신은 HTTPS이며 로컬 관리 화면은 loopback HTTP입니다. 관리 세션은 HttpOnly/SameSite cookie를 사용하며 12시간 동안 유지됩니다.

업로드 작업 및 API 응답 사본은 등록 후 최대 30일 이내에 앱이 실행 중일 때 정리합니다. 앱 종료 중 지난 기한은 다음 시작에서 적용합니다. 채널은 30일 이내 검증이 없으면 저장 토큰과 해당 API 작업을 삭제하고 재연결을 요구합니다. 공개 영상 발견 자료와 수집 체크포인트는 30일 만료 또는 새 수집으로 교체합니다. 중복 방지용 최소 경기 예약과 사용자가 입력한 설정은 사용자가 삭제할 때까지 남습니다. 정책 동의 버전·시각도 로컬에 저장합니다.
