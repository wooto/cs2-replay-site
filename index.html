CS2 Replay Local Admin

A local Windows application for channel owners managing CS2 replay videos.

CS2 개인 경기 영상을 여러 YouTube 채널에 게시하기 위한 로컬 관리 도구입니다. 영어·러시아어·브라질 포르투갈어 채널을 각각 설정하고, OAuth 연결과 대상 채널을 확인합니다.

This public website provides product information and policies. The operational dashboard runs only on the operator’s Windows PC at a loopback address. No Google approval or completed live upload verification is claimed.

What the current application does

  • Connects and verifies each channel separately using Google OAuth with PKCE.
  • Recommends verified FACEIT matches using performance (90%) and recency (10%), without YouTube statistics.
  • Accepts owner-selected local MP4 files and metadata; supports resumable uploads, cancellation and recovery.
  • Requires a private first-upload test; lets owners explicitly choose private, unlisted or public for production uploads.
  • Requires capture and reviewer evidence for public uploads. Match scores do not certify recording quality.
  • Provides policy agreement, local deletion and 30-day expiry of API copies.

Automatic demo download, full POV recording integration, custom thumbnail upload and editing existing YouTube videos are outside this release.

YouTube API permissions

youtube.readonly verifies the authorized channel and uploaded-video identity, visibility and processing. youtube.upload sends owner-selected files and metadata. Google login and consent occur on Google’s website; this application does not collect passwords.

Optional public player-name discovery uses API-key search metadata. It is disabled by default and does not contribute statistics to recommendation scores.

Data flow and user controls

The owner authorizes each channel on Google’s website. The local app compares the authorized channel ID with the registered destination, sends the selected MP4 and metadata to YouTube, and checks returned visibility and processing. Google passwords are never collected. Tokens and resumable session URLs are encrypted using Windows DPAPI.

Before using the app, the owner accepts its policies. Local data deletion, channel disconnect and 30-day expiry of API copies are available. Uploaded videos and original source files are managed separately. See the Privacy Policy for the full data lifecycle.

Current verification status

The Google Cloud project is independently named CS2 Replay. Automated fixture tests validate implementation behavior; actual owner consent, channel verification, refresh and private test upload evidence are still pending. This website does not claim Google approval, a quota increase, a successful live upload or predicted audience performance.

Installation and reviewer access

The source repository is wooto/cs2-replay. Build on Windows with Go, then run cs2replay.exe admin and open the one-use launch link on that PC. The admin binds to 127.0.0.1:8787. A reviewer cannot access the operator’s loopback dashboard remotely. Contact the operator for an installation or supervised demonstration arrangement.
